# 透明玻璃

[首页](../../README.zh-CN.md) · [English](../en/CLEAR_GLASS.md)

在铸造盆中浇铸 1,000 mB 熔融玻璃可获得透明玻璃。用八块透明玻璃围住一个染料，可合成八块染色透明玻璃。十六种颜色均沿用匠魂怀古的连接方式、物品名、着色值和信标颜色。相邻方块的类型与颜色相同才会连接。染色变体位于冶炼创造栏。

透明玻璃、染色透明玻璃和普通染色玻璃每块都可熔成 1,000 mB 熔融玻璃。透明与染色透明玻璃使用 NeoForge 通用玻璃和颜色标签。两者都是装饰方块，与冶炼炉和工匠储罐墙体使用的焦黑玻璃分开。

默认需要精准采集才能回收透明或染色透明玻璃。在 `config/tconstruct-common.toml` 的 `[smeltery]` 下设置 `clearGlassSilkTouch = false` 可允许普通采集。两种配置均保留单块掉落和正常的爆炸掉落规则。设置和物品名支持简体中文与英文。

透明玻璃、焦黑玻璃及焦黑储罐透过天空光，不传导红石，也不会使实体窒息。完整焦黑墙体遮挡光线并传导红石。单独放置的玻璃方块会显示完整边框，玩家放置和命令放置均适用。
