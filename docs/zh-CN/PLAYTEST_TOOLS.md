# 工具系统手工验证

[首页](../../README.zh-CN.md) · [English](../en/PLAYTEST_TOOLS.md)

使用构建后的 `build/libs/TinkersNirvana-1.21.1-1.0.3.jar`，Minecraft 1.21.1 / NeoForge 21.1.218。以下是待执行的实际客户端验证，未以编译或资源审计替代。

| 场景 | 操作 | 预期 |
| --- | --- | --- |
| 部件与基础组装 | 合成模板和装配台，右键/潜行右键选部件，制作杆、头部和护手，再组装大剑 | 手柄、护手、剑刃依次从下往上排列。模板保留，领取结果时才消耗材料，名称与材质正确 |
| 高级工具 | 在普通装配台与锻造台分别尝试锤、劈刀、长弓、弩箭 | 高级模式仅在锻造台开放，三/四部件按图标正确组装 |
| 拒绝与取消 | 放错部件、不同材料混加工、缺材料；预览后改模式或关界面 | 不产生错误结果，不消耗原料，不复制工具 |
| 整批产物 | 用一块木板加工两个碎片，分别左键、右键和 Shift 领取；再测试背包满和只剩一件空间 | 每批完整发放；背包满时不消费，部分空间时余量掉落给玩家 |
| 强化与修复 | 损伤工具后修复；加入钻石、红石、石英；用光强化槽，再尝试强化 | 属性、耐久、进度与槽数变化正确；无槽配方被拒绝 |
| 互斥与压印 | 尝试精准采集与幸运互斥；完整配方压印一次，再重复；套件加燧石磨制 | 不兼容与重复压印被拒绝，磨制只提高等级 |
| 拆解与清理 | 满耐久工具预览拆解后取消，再正式取第一个部件；分别在预览/已领取状态拆掉工作台 | 取消返还一把原工具；提交后仅保留部件；清理不同时掉落源工具与预览部件 |
| 采集 | 锤/挖掘机范围采集、潜行单格、连锁原木、短镰/大镰收割与剪羊 | 仅处理适用方块，成熟作物留下种子重种，方块实体和不可破坏方块保留 |
| 近战动作 | 长剑突进、细剑后跳、锅蓄力、牌子正面格挡/反射与背面受击、劈刀副手限制 | 动作、击退、攻击速度、方向检查与耐久正常；损坏工具不继续格挡 |
| 材料词条 | 木质生态、石制词条、铅中毒、钢流血、钴动量、玛玉灵贪婪、海绵柔和 | 效果可触发，冷却/状态按物品保存；柔和零伤害并提供精准采集 |
| 弓与弹药 | 普通箭/药箭/自制箭射击；中断拉弓；弩半途取消与完整装填后退出重进；投掷手里剑再回收 | 动画分阶段、取消不扣弹药、装填保存、每发只扣一次、回收不复制整份弹药 |
| 弹药边界 | 射出最后一发、回收相同与不同材料弹药、分裂箭回收 | 空弹药仍保留并可修复；只补充相同材料与强化；额外分裂箭不可回收 |
| 灵魂绑定与苔藓 | 生存死亡后重生；低于/达到五级经验时用苔藓球点书架；储存经验后等待修复 | 绑定工具归还且无地面副本；经验门槛与消耗正确，修复逐步发生 |
| 画面、声音与同步 | 检查全部工具分层/破损/弓弩状态、Shift/Alt；试听锅、柔和、充放电、装填；多人交互 | 无缺失纹理、材质和文本，特殊声音可听见，物品状态和工作台操作同步 |

若已有领地保护或事件取消工具，再针对范围破坏、光斑放置和投射物发射执行拒绝场景：应遵守原生事件取消，不继续破坏、生成光斑或扣除未发射的弹药。
