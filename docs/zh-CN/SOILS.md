# 土壤与史莱姆水晶

[首页](../../README.zh-CN.md) · [English](../en/SOILS.md)

史莱姆创造栏提供绿色黏液泥、蓝色黏液泥、岩浆黏液泥、墓地土、神圣土及绿、蓝、岩浆史莱姆水晶。水泥保留在冶炼创造栏，注册 ID 沿用原值。

六种土壤的硬度和抗爆性均为 3，摩擦力为 0.8，使用沙质音效，适合用铲挖掘。徒手也能获得掉落，方块不会像沙子一样下落。踩在绿、蓝黏液泥上，水平速度乘以 0.4，竖直速度不变，并短暂获得虚弱 I。岩浆黏液泥没有额外的行走效果。亡灵踩在墓地土上时，每次行走回调恢复 1 点生命。神圣土对亡灵造成 1 点魔法伤害并使其燃烧 1 秒，玩家和其他生物不受影响。

| 产物 | 原料 |
| --- | --- |
| 3 份水泥 | 黏土球、沙子、砂砾 |
| 12 份水泥 | 黏土块、4 份沙子、4 份砂砾 |
| 绿色黏液泥 | 4 个原版黏液球、沙子、泥土 |
| 蓝色黏液泥 | 4 个蓝色黏液球、沙子、泥土 |
| 绿色或蓝色黏液泥 | 对应凝固黏液块、沙子、泥土 |
| 岩浆黏液泥 | 2 个岩浆黏液球、2 个岩浆膏、灵魂沙、下界岩 |
| 墓地土 | 泥土、腐肉、骨粉 |

沙子使用 `c:sands`，水泥配方中的砂砾使用 `c:gravels`。绿、蓝黏液泥配方通过 `tconstruct:soil_recipe_dirt` 接受泥土、砂土和灰化土，墓地土需要普通泥土。

烧炼墓地土 200 刻可获得神圣土和 0.1 经验。烧炼任意黏液泥 200 刻可获得对应水晶和 0.75 经验。原版熔炉和焦黑熔炉均支持这些普通烧炼配方。水晶提供 `c:slime_crystals/<color>` 标签供扩展使用。

绿、蓝黏液泥不支持普通植物。数据包可通过 `tconstruct:slime_plants` 方块标签扩展专用植物。黏液树木、植物和空岛的生成见[世界生成](WORLD.md)。
