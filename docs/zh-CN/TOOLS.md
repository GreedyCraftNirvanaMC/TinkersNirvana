# 工具与部件

[首页](../../README.zh-CN.md) · [English](../en/TOOLS.md)

面向 Minecraft 1.21.1 / NeoForge。工具使用现有材料组件、词条框架、装配台和冶炼系统；原有镐的物品 ID 保持为 `tconstruct:pickaxe/pickaxe`。

## 制作流程

1. 用两根木棍和两块木板交叉合成四个空白模板。模板右键切换部件，潜行右键反向切换。
2. 用空白模板制作模板桌、部件加工台和工具装配台。在模板桌选择部件，将得到的模板和原料放入部件加工台；领取一个部件，余料转为碎片，模板保留。原有装配台修复模式也继续支持模板批量加工。
3. 木材、石头、燧石、骨头、仙人掌等可直接加工。金属部件使用现有浇筑台：先以部件制作金属铸模，再倒入对应熔融材料；黏土铸模使用后消耗。
4. 在工具模式中按槽位图标放入部件，领取组装结果。工具锻造台由三块焦黑砖块、四块金属块和工具装配台合成，开放高级工具；支持铁等十四类金属。

加工会完整分配投入的材料。原木等高价值原料可一次产出多个部件；无法整分的配方不会消耗输入，可改用木板、碎片等原料。默认模式中的工具槽是中央槽，组装模式按工具部件结构排列槽位，并用图标提示输入。

## 工作台、储存与修复

合成站保留九格输入，支持原版配方书和邻接容器。相邻工作台可通过顶部页签切换。模板箱储存模板或铸模，每种模板或铸模保留一份；部件箱按材料与组件区分部件，两种箱子各有 256 格并提供翻页。

部件加工台连接模板箱时，可左击侧栏模板与当前模板交换。工具装配台可访问相连的部件箱。箱子默认在拆除后保留内容，受 `general.chestsKeepInventory` 控制；木材和金属外观随配方原料、放置、掉落及中键复制保留。

修复模式可更换实际部件，并保留工具损耗、独立强化及可保留的词条状态。名称框可为新工具命名，也可单独重命名现有工具。磨制套件加燧石可改变采掘等级，包括降低等级；单独用套件可在合成栏修复工具。

主手持有采掘工具且对目标无效时，可自动使用有效的副手工具；正确工具承担耐久、掉落和词条。主手有效时继续使用主手。`client.renderInventoryInWorld` 控制桌面物品显示，三个 `client.listAll*` 开关控制创造栏材料变体。

宝典与完整工作台说明见 [BOOK.md](BOOK.md)，装置和世界内容见 [GADGETS.md](GADGETS.md)、[WORLD.md](WORLD.md)。

所有模式共用六个物理输入槽与一个结果槽。切换模式保留输入；不符合当前配方的多余输入会阻止组装。批量产物右键也整批领取；背包只能装下部分时，快捷领取的余量按原版合成台方式掉落给玩家。

弩箭核心由箭杆在浇筑台上包覆两份可浇筑材料获得。组装和拆解均保留箭杆与包覆层两种材料。磨制套件和碎片也在部件目录中。

范围采集时潜行可改为单方块。额外方块逐个通过玩家的原版破坏流程，保留保护事件和掉落检查；不处理负硬度方块、方块实体、未加载区块或不适用的方块。连锁伐木有数量和距离上限。

弹药以工具耐久保存，每发使用十点耐久。回收时优先补充相同材料与强化的弹药，找不到可补充的弹药时获得仅余一发的弹药物品。分裂产生的额外投射物不可回收。普通箭与药箭沿用原版箭实体。

## 修复、强化与拆解

- 默认模式：工具放中央，其余槽放材料或强化物。预览只修改副本，领取后才消耗输入。
- 常见强化：红石、石英、青金石、钻石、绿宝石、烈焰粉、活塞、发酵蛛眼、神圣土等。青金石保留分阶段进度；精准采集与幸运互斥。
- 加固板、丝绢宝石、熔岩水晶和扩展器使用配方制作。凋零骷髅掉落凋零之骨；骨头浇覆鲜血获得血骨。
- 苔藓球对书架等具有附魔增幅的方块使用，消耗五级经验转为生态修复苔藓。强化后的工具从经验中储存修复能量，在快捷栏或副手中逐步修复。
- 磨制套件加燧石设置挖掘等级，可高于或低于原等级；不会替换原来的材料词条。
- 部件加绿、蓝、岩浆史莱姆水晶及金块可压印一次，获得该部件对应的材料词条。重复压印和不兼容词条会被拒绝。
- 完整耐久工具可在拆解模式中还原部件。领取第一个部件才提交拆解；提交前切换模式会返还原工具。损坏工具仍保留物品，可用材料修复。
- 灵魂绑定在死亡后归还工具；其他掉落仍走原版流程。

Shift 查看属性、材料和剩余强化槽，Alt 查看词条说明。材料属性按 Antique 源码配置；旧工具继续读取已保存的属性，修复、强化或重算时保留未知组件。

## 工具与合成配置

配置位于 `config/tconstruct-common.toml`：

| 配置 | 默认值 | 作用 |
| --- | --- | --- |
| `general.craftCastableMaterials` | `false` | 允许部件加工台使用可浇铸材料 |
| `general.addFlintRecipe` | `true` | 三块砂砾合成一枚燧石，重载配方时生效 |
| `general.craftingStationBlacklist` | `[]` | 按方块 ID、方块实体类型 ID 或完整类名排除合成站相邻储存 |
| `tools.deconstructTools` | `true` | 允许拆解工具 |
| `tools.vanillaToolBreaking` | `false` | 开启后，耗尽耐久会销毁工具 |
| `tools.oldMattockAndKama` | `false` | 默认鹤嘴锄铺路、短镰耕地；开启后鹤嘴锄耕地，短镰不耕地 |
| `tools.repairToolsOnAnvils` | `false` | 允许工具参与原版铁砧处理 |
| `tools.autosmeltFortuneInteraction` | `false` | 自动冶炼时启用 Antique 的额外幸运产量 |
| `tools.despawnProjectile` | `1200` | 自定义弹药落地后的消失刻数；不毁弹药使用十分之一时间 |

空白模具需要先选择部件，再用于加工。斩首掉落与实体熔炼配置见 [TOOL_API.md](TOOL_API.md)。
